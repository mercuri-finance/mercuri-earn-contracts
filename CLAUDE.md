# Separate Mercurifi Earn contracts repository — Claude

This Git repository owns the Mercurifi Earn contracts, apart from the Launch, Trade and Agent Accounts contract sets: source, tests, release tooling, deployment inputs and the deployment records. In the Mercurifi workspace it lives at `contracts/earn`. Today it holds one contract, `TestLendVault`, an Arc testnet stand-in for a lending venue; nothing is deployed, and nothing here may reach Arc mainnet (the deployment script refuses it). Phase 2 range vaults land here after their own spec and review. Never change Launch's, Trade's or Agent Accounts' contracts from here; flag any need for them to the owner. Run `bash script/check-contracts.sh` for a candidate change, keep every `lib/` submodule at its recorded pin (`lib-versions.md`) and update `source-manifest.json` with every reviewed `src/` change. Before any commit, push, PR or issue, follow the identity gate in `../../docs/agents/release.md`: login, author, committer and HTTPS push transport must all be `mercurifinance`, with no AI `Co-authored-by` trailer. Keep the repository public-clean: no personal or company names, local paths, private repository names, internal hosts or keys. Local builds and tests do not authorize a broadcast, governance action or deployment record. Never read `.env` or disclose signer material. Use the workspace `.claude/skills/mercuri-contract-assurance/` for a contract review.
